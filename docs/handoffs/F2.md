## Verhalten und Entscheidungen
- Das System nennt weder Namen des Fokus noch ein „aus“-Signal verlässlich: Die Absicht hat `mode` als Optional; fehlt er (Fokus endet, Standardwerte), gilt „Fokus beendet“ anhand des gespeicherten Zustands. Wechsel Fokus A → B wird als Übergabe behandelt (kein Stopp). Name des Fokus ist ein optionaler Parameter, nur für Mitteilungstexte.
- Nachfragen nutzt nur Snapshot und einen Schlüsselbund-Check (kein Netz). Automatisch fragt den Server einmal (`GET /time/timer`), prüft Art/Herkunft (gespeicherte Segment-ID des vom Filter gestarteten Timers) und startet mit stabiler `clientEventId` je Aktivierung. Nach echter Aktion: Widget-Aktualisierung (`WidgetPublisher.refresh`) erst nach dem Protokolleintrag.
- Zeitkritisch (`timeSensitive`) bewusst nicht: braucht Entitlement; Rückfragen sind „aktiv“. Hinweis in der Seite: Timetrack in „Erlaubte Apps“ des Fokus aufnehmen.
- Schalter „Auch von Hand gestartete Timer beenden“ (Standard aus) in der App Group.
- Server `automation`-Schalter wird per `.focusSync` als `automationEnabled` gespiegelt; aus = nichts tun.

## Manueller Testplan (iPhone)
1. Build installieren, anmelden, Einstellungen › Fokus-Filter öffnen, Mitteilungen erlauben.
2. iOS-Einstellungen › Fokus › Arbeit › Fokusfilter › Timetrack: Modus „Nachfragen“, Art Arbeit, Name „Arbeit“; Timetrack in „Erlaubte Apps“.
3. Fokus Arbeit einschalten: Mitteilung „Fokus „Arbeit“ ist an – Timer starten?“; „Start“ tippen; Timer läuft (App/Widget prüfen).
4. Fokus ausschalten: „Timer stoppen?“ erscheint; „Stopp“ tippen. Erneut mit „Weiterlaufen lassen“.
5. Modus „Automatisch“: an → Timer startet ohne Rückfrage; aus → stoppt. Zusätzlich: Timer von Hand starten, dann Fokus an/aus: bleibt unberührt; Schalter „Auch von Hand …“ an: wird gestoppt. Timer Art Fahrt laufen lassen: wird nie gestoppt.
6. Abgemeldet: Fokus an → Hinweis „Bitte in Timetrack anmelden“.
7. Seite „Fokus-Filter“: Status „Aktiv: …“ und letzte Aktionen prüfen; wenn beim Ausschalten nichts gestoppt wird, dies melden (Annahme zur Abmeldung).
