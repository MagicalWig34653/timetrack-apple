# V3 – Urlaub nativ: geplanter Urlaub im Ring, Filter/Sortierung, Anhänge (iOS/iPadOS, macOS baut mit)

Branch `v3-vacation-native` (Worktree `timetrack-apple-wt/v3`, von `main`). **Build-Nummer nicht erhöht, nichts hochgeladen, nicht gepusht.** Vertrag: Backend 0.24.0 (B6: `attachmentCount`, `hasAttachment`, `disposition=inline`). Referenz: PWA-Abwesenheitsliste (P5).

## Umfang
1. **Urlaubs-Ring** (`Sources/Planning/VacationScreen.swift`, einziger Ring dieser Art; Widgets/Komplikationen zeigen keinen Urlaub): neuer `SegmentedRing` in `TimetrackDesign` mit drei Anteilen – genommen/genehmigt (durchgezogen, Blau), geplant bzw. angefragt (schraffiert, Bernstein, radiale Streifen), frei (Spur). Kurze Legende unter dem Ring (Punkt voll / schraffiert / Ring leer, mit Tagen), Warnzeile bei „mehr geplant als verfügbar“. Barrierefreiheit: Muster statt nur Farbe; der Ring trägt einen gesprochenen Satz („Urlaubsverbrauch: 8 Tage genommen oder genehmigt, 10 Tage geplant, 12 Tage frei“), die Legende ist für VoiceOver ausgeblendet (keine Doppelung). Reine Logik `VacationRingSegments` (Kern): Kapazität = gebucht + verfügbar (stimmt auch bei Stichtagsbestand und verfallenem Übertrag), Überplanung füllt den Ring und wird gemeldet.
2. **Filtern/Sortieren** (`AbsenceListOptions` im Kern, `AbsenceFilterBar`/`AbsenceFilterSheet` in `VacationTools.swift`): Art, Status, Zeitraum (alle / aktuell und kommend / vergangen / eigener Zeitraum mit offenen Grenzen, Überschneidungslogik), Anhang (alle/mit/ohne), Sortierung nach Datum/Art/Status (Status in Ablaufreihenfolge geplant → angefragt → genehmigt → genommen) mit Umkehrknopf. Eine schlanke Zeile über der Liste öffnet das Blatt, zeigt „n Filter aktiv · Sortiert nach …“, „x von y“ und ein Zurücksetzen-Kreuz. Auswahl wird in `UserDefaults` gemerkt (`PlanningStore.listOptions`, Schlüssel `vacation.absenceListOptions.v1`; Standardwerte löschen den Schlüssel; kaputte Daten fallen auf Standard). Bei Standardsortierung bleibt die Gruppierung „Geplant / Genehmigt, genommen“ wie zuvor; bei anderer Sortierung eine einzige Liste „Ergebnisse“ (Gruppen würden die Reihenfolge zerreißen). Der Filter wirkt auf das geladene Jahr (Hinweis im Blatt).
3. **Anhänge**: `Absence.attachmentCount` (fehlt bei älterem Server → 0), `FileMeta`, `APIClient.listAbsenceAttachments`, `downloadFile(id:inline:)` (`disposition=inline` nur für die Whitelist des Servers), `listAbsences(hasAttachment:)`. Liste: Büroklammer (mit Zahl ab 2) als eigener Knopf (44 pt) rechts neben der Zeile, VoiceOver „2 Anhänge“. Tippen öffnet `AbsenceAttachmentsSheet` (Liste mit Name, Größe, Symbol), Tippen auf eine Datei lädt sie in ein temporäres Verzeichnis (Dateiname bereinigt, je Datei-ID getrennt, iOS: Dateischutz „complete“) und zeigt sie mit QuickLook (`quickLookPreview`; PDF, Bilder, Text und was das System sonst kann). Temp-Dateien werden beim Schließen gelöscht.
